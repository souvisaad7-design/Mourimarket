# نشر موقع Souk Chinguetti على الإنترنت — خطوة بخطوة

## الخيار (أ): Vercel + Supabase، وهو الموصى به إذا كانت حساباتك مربوطة مسبقاً

المستودع يحتوي على `vercel.json` و`api/index.js`. الواجهة تُنشر كملفات ثابتة على شبكة Vercel، والـ API يعمل كدالة serverless.

1. **قاعدة بيانات خاصة بالموقع:** في Supabase أنشئ مشروعاً جديداً باسم `maurimarket` (المنطقة Paris). **لا تستعمل مشروع `awn-wa-sanad-membership`**، فهو لتطبيق آخر، وفيه جداول قد تتعارض أسماؤها (مثل `users`).
2. **مشروع Vercel:** في https://vercel.com/new اختر **Import** للمستودع `souvisaad7-design/Mourimarket`، واترك إعدادات Build كما هي، فهي تُقرأ من `vercel.json`.
3. **ربط Supabase:** في مشروع Vercel افتح **Storage** (أو **Integrations**) ثم **Supabase** ثم **Connect**، واختر مشروع `maurimarket`. يضيف هذا المتغير `POSTGRES_URL` تلقائياً، والموقع يقرؤه مباشرة. إن لم تستعمل التكامل، فأضف `DATABASE_URL` يدوياً برابط **Transaction pooler** (المنفذ 6543).
4. **المتغيرات:** في **Settings ← Environment Variables** أضف:

   | المفتاح | القيمة |
   |---|---|
   | `JWT_SECRET` | نص عشوائي طويل (40 حرفاً أو أكثر) |
   | `ADMIN_EMAIL` | بريد المدير |
   | `ADMIN_PASSWORD` | كلمة مرور قوية للمدير |
   | `DB_POOL_MAX` | `3` |

5. **Deploy:** أثناء البناء تُنشأ الجداول والتصنيفات وحساب المدير تلقائياً. بعدها افتح الرابط `https://<project>.vercel.app`.
6. **التحقق:** افتح `/api/health`، وسجّل الدخول كمدير، ثم انشر إعلاناً بصورة ووافق عليه.

> كل `push` إلى `main` يُنشر تلقائياً. حجم الطلب في Vercel محدود بـ 4.5 ميغابايت، والصور تُضغط في المتصفح قبل الرفع لتبقى ضمن الحد.

## الخيار (ب): Render + Supabase

مكوّنات النشر، وكلها مجانية للبدء:

```
GitHub (الكود)  ──►  Render (يشغّل الموقع: الواجهة + الـ API)  ──►  Supabase (قاعدة البيانات PostgreSQL + الصور)
```

* **GitHub**: المستودع `souvisaad7-design/Mourimarket`. كل `push` يعيد نشر الموقع تلقائياً.
* **Render**: يبني المشروع ويشغّله ويعطيك رابطاً مثل `https://maurimarket.onrender.com`.
* **Supabase**: قاعدة البيانات. الصور المرفوعة تُحفظ فيها أيضاً، فلا تضيع عند إعادة التشغيل.

الوقت المتوقع: 20 إلى 30 دقيقة.

---

## المرحلة 1: إنشاء قاعدة البيانات على Supabase

1. ادخل إلى https://supabase.com/dashboard
2. اضغط **New project**.
3. اختر المؤسسة `fatimetouhsn-cmd's Org`، ثم املأ الحقول:
   * **Name:** `maurimarket`
   * **Database Password:** اضغط **Generate a password** ثم **احفظ كلمة المرور** في مكان آمن، فستحتاجها في الخطوة 6.
   * **Region:** `West EU (Paris)`
4. اضغط **Create new project** وانتظر دقيقتين حتى يصبح جاهزاً.
5. اضغط زر **Connect** في أعلى الصفحة.
6. انسخ الرابط من قسم **Session pooler**، وليس Direct connection، لأن Render المجاني لا يدعم الاتصال المباشر. يبدو الرابط هكذا:
   ```
   postgresql://postgres.xxxxxxxx:[YOUR-PASSWORD]@aws-0-eu-west-3.pooler.supabase.com:5432/postgres
   ```
   ضع كلمة المرور من الخطوة 3 مكان `[YOUR-PASSWORD]`، بدون الأقواس.

> ✅ لا حاجة لإنشاء الجداول يدوياً، فالموقع ينشئها تلقائياً عند أول تشغيل.

---

## المرحلة 2: نشر الموقع على Render وربطه بـ GitHub

7. ادخل إلى https://render.com واضغط **Get Started**، ثم سجّل الدخول بزر **GitHub**. هكذا يرتبط Render بحسابك على GitHub.
8. من لوحة التحكم اضغط **New +**، ثم **Blueprint**.
9. اضغط **Connect GitHub**. إذا طلب منك صلاحيات، اختر **Only select repositories** ثم المستودع `Mourimarket`، ثم **Install**.
10. اختر المستودع `souvisaad7-design/Mourimarket`. سيقرأ Render ملف `render.yaml` الموجود فيه تلقائياً.
11. سيطلب منك 3 قيم:

    | المفتاح | القيمة |
    |---|---|
    | `DATABASE_URL` | رابط Supabase من الخطوة 6 |
    | `ADMIN_EMAIL` | بريدك الذي ستدخل به كمدير، مثلاً `admin@yourmail.com` |
    | `ADMIN_PASSWORD` | كلمة مرور قوية للمدير (12 حرفاً على الأقل) |

    أما `JWT_SECRET` فيولّده Render تلقائياً.
12. اضغط **Apply**. يبدأ البناء ويستغرق 3 إلى 5 دقائق. تابع السجل (Logs) حتى تظهر الرسالة:
    ```
    Souk Chinguetti API listening on ...
    ```
13. افتح الرابط الظاهر أعلى الصفحة، مثل `https://maurimarket.onrender.com`. **🎉 موقعك يعمل الآن.**

---

## المرحلة 3: التحقق بعد النشر

14. افتح `https://<رابطك>/api/health`، ويجب أن يظهر `{"ok":true}`.
15. سجّل الدخول ببريد وكلمة مرور المدير من الخطوة 11، وستصل إلى **لوحة الإدارة**.
16. أنشئ حساباً عادياً من نافذة خاصة، وانشر إعلاناً تجريبياً بصورة.
17. من لوحة الإدارة، اذهب إلى **الإعلانات** ووافق على الإعلان، وتأكد أنه ظهر في الصفحة الرئيسية.

> ملاحظة: قاعدة البيانات في الإنتاج تبدأ فارغة، ففيها التصنيفات التسعة وحساب المدير فقط، بدون الحسابات والإعلانات التجريبية.

---

## المرحلة 4 (اختيارية): اسم نطاق خاص مثل `maurimarket.mr`

18. اشترِ النطاق من مزوّد نطاقات. نطاقات `.mr` تُسجَّل عبر مسجّلين معتمدين لدى NIC Mauritanie، أو اختر نطاق `.com`.
19. في Render، افتح الخدمة ثم **Settings** ثم **Custom Domains** ثم **Add Custom Domain**، واكتب النطاق.
20. أضف سجلات DNS التي يعرضها Render (عادةً `CNAME` أو `A`) في لوحة مزوّد النطاق. شهادة HTTPS تُفعَّل تلقائياً.
21. في **Environment** أضف المتغير `CORS_ORIGIN=https://maurimarket.mr`، فهو يُستخدم في روابط استعادة كلمة المرور.

## التحديثات لاحقاً

أي تعديل يُرفع إلى الفرع `main` على GitHub يُنشر تلقائياً على Render خلال بضع دقائق، ولا حاجة لأي خطوة إضافية.

## حدود الخطة المجانية

| الخدمة | الحد | الحل عند النمو |
|---|---|---|
| Render Free | يتوقف الموقع بعد 15 دقيقة بدون زيارات، وأول زيارة بعدها تستغرق قرابة 50 ثانية | الترقية إلى خطة **Starter** (حوالي 7$ شهرياً) |
| Supabase Free | 500 ميغابايت للقاعدة، أي آلاف الإعلانات مع صورها المضغوطة، ويتوقف المشروع مؤقتاً بعد أسبوع بدون نشاط | خطة **Pro**، أو نقل الصور إلى Supabase Storage |

## حل المشاكل الشائعة

| المشكلة | السبب والحل |
|---|---|
| خطأ `ENETUNREACH` أو `ECONNREFUSED` في السجل | استخدمت رابط Direct connection. استبدله برابط **Session pooler** (الخطوة 6) |
| خطأ `password authentication failed` | كلمة مرور قاعدة البيانات خاطئة في `DATABASE_URL`، أو بقيت الأقواس `[ ]` حولها |
| `Set ADMIN_PASSWORD ...` | لم تُدخل `ADMIN_PASSWORD` في Render. أضفه من **Environment** ثم **Manual Deploy** |
| تفتح الصفحة ببطء أول مرة | هذا طبيعي في الخطة المجانية (انظر الجدول أعلاه) |
| نسيت كلمة مرور المدير | تغيير `ADMIN_PASSWORD` لا يفيد بعد أول تشغيل. استعمل «نسيت كلمة المرور»، ورابط الاستعادة يظهر في سجل Render (Logs) لأن خدمة البريد غير مربوطة بعد |
